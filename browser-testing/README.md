# browser-testing — Browser Automation via ABP & Playwright

Two modes:
- **Interactive (ABP)**: Pre-built scripts for navigation, screenshots, clicking, element picking — extremely fast, handles page settling automatically
- **Scripted (Playwright)**: Ad-hoc JS for complex multi-step flows

Includes tools: `browser-nav.js`, `browser-screenshot.js`, `browser-click.js`, `browser-type.js`, `browser-pick.js`, `browser-content.js`.
