# bishkek-report — Fictional Focus Group UX Review

Summon 8–12 fictional but statistically plausible people from Kyrgyzstan to judge your web app. They take screenshots, click around, get confused, and write honest reviews in Russian.

Diverse cast: a 72-year-old on a Galaxy A13, a student on a Xiaomi, a developer with DevTools open, a journalist in a hurry.
